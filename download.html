Post-Install & Verification Notes
  • Built-in Typst Compiler: Azo Type bundles Typst 0.15.1 and 17 embedded fonts out of the box—no separate typst CLI installation is required.
  • macOS Sonoma 14+ & Signing: Both Apple Silicon and Intel macOS builds target macOS 14 Sonoma or newer and are ad-hoc signed. If Gatekeeper blocks first launch, Control-click Azo Type.app and choose Open.
  • Optional Downloads: Legacy Typst versions (0.14.2, 0.13.1, 0.12.0) and Tier-1 offline spell/grammar packs are verified with SHA-256 checksums before activation.
  • Smoke Verification: Run azo-type --screenshot /tmp/out.png to verify graphics initialization and headless rendering.
Build Optimized Binary from Source

Requires Rust 1.80+ and (on Linux) libfontconfig1-dev plus X11/Wayland headers.

git clone https://github.com/azocloud/azo-type.git
cd azo-type
cargo build --release --manifest-path app/Cargo.toml
./target/release/azo-type
