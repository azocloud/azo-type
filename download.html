Linux

x86_64 · aarch64 (Wayland & X11)

In-window desktop menu bar, GTK/portal native file dialogs via rfd, and hardware-accelerated OpenGL (glow) viewport.

System Requirements

  • Wayland or X11 display server
  • fontconfig runtime & OpenGL drivers
  • Building from source requires libfontconfig1-dev and X11/Wayland dev headers

macOS

Apple Silicon (aarch64) · Intel (x86_64)

Integrates a native macOS screen-top menu bar via muda, Cmd-based keyboard shortcuts, and native NSOpenPanel / NSSavePanel dialogs.

System Requirements

  • macOS 12 Monterey or newer recommended
  • Universal or architecture-specific .app / .dmg / tarball
  • Xcode Command Line Tools required when building from source
Get macOS Build

Windows

x86_64 · aarch64 (MSVC)

In-window menu bar, Win32 native file pickers, embedded application icon resources, and Ctrl-based shortcuts.

System Requirements

  • Windows 10 or Windows 11 (64-bit)
  • Microsoft Visual C++ Redistributable / OpenGL-capable GPU driver
  • MSVC Rust toolchain required when building from source

Post-Install & Verification Notes
  • Built-in Typst Compiler: azo-type bundles Typst 0.15.1 and 17 embedded fonts out of the box—no separate typst CLI installation is required.
  • Optional Downloads: Legacy Typst versions (0.14.2, 0.13.1, 0.12.0) and Tier-1 offline spell/grammar packs are verified with SHA-256 checksums before activation.
  • Smoke Verification: Run azo-type --screenshot /tmp/out.png to verify graphics initialization and headless rendering.
Build Optimized Binary from Source

Requires Rust 1.80+ and (on Linux) libfontconfig1-dev plus X11/Wayland headers.

git clone https://github.com/azocloud/azo-type.git
cd azo-type
cargo build --release --manifest-path app/Cargo.toml
./app/target/release/azo-type
