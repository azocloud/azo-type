azo-type targets **Linux** (Wayland & X11, `x86_64` & `aarch64`), **macOS** (Apple Silicon `arm64` & Intel `x86_64`, **macOS 14 Sonoma or newer**), and **Windows** (`x86_64` & `aarch64`).

<Callout type="warn" title="Alpha Release">
  azo-type is currently in **alpha** development. Pre-built desktop binaries are now available on the [Download page](/download) and [GitHub Releases](https://github.com/azocloud/azo-type/releases/latest), though bugs and breaking changes may still occur.
</Callout>

## Release Binaries

Pre-built release archives are automatically published on [GitHub Releases](https://github.com/azocloud/azo-type/releases/latest) and linked directly from the [Download page](/download):

| Platform | Architectures | Archive | Minimum OS |
| :--- | :--- | :--- | :--- |
| **Linux** | `x86_64`, `aarch64` | `.tar.gz` (`azo-type` + `azo-type.desktop`) | Wayland or X11, `fontconfig`, OpenGL |
| **macOS** | `arm64` (Apple Silicon), `x86_64` (Intel) | `.tar.gz` (`Azo Type.app`) | **macOS 14 (Sonoma) or newer** |
| **Windows** | `x86_64`, `aarch64` | `.zip` (`azo-type.exe`) | Windows 10 / 11 (64-bit) |

1. Download the archive matching your operating system and CPU architecture on the [Download page](/download) (which detects your platform automatically when supported by your browser).
2. Extract the archive and launch the `azo-type` executable (`azo-type.exe` on Windows, `Azo Type.app` on macOS). On macOS, if Gatekeeper prompts on an ad-hoc signed alpha build, Control-click `Azo Type.app` and choose **Open**.
3. Typst `0.15.1` and 17 bundled fonts are embedded inside the application, so no external `typst` CLI installation is required.

## Building from Source

### Prerequisites

- **Rust `1.80+`** (stable toolchain via [rustup](https://rustup.rs/))
- **C compiler toolchain** (`gcc`/`clang` on Linux, Xcode Command Line Tools on macOS, MSVC Build Tools on Windows)
- **Linux system libraries:** `fontconfig` development headers plus X11/Wayland libraries

On Debian/Ubuntu Linux, install the required development packages before compiling:

```bash
sudo apt-get update
sudo apt-get install -y libfontconfig1-dev libxkbcommon-dev libwayland-dev libx11-dev libxcb-shape0-dev libxcb-xfixes0-dev
```

### Compile and Run

Clone the repository and build the desktop application from `/app`:

```bash
git clone https://github.com/azocloud/azo-type.git
cd azo-type

# Run debug build
cargo run --manifest-path app/Cargo.toml

# Or build an optimized release binary (LTO fat, stripped)
cargo build --release --manifest-path app/Cargo.toml
```

The release profile in `Cargo.toml` uses `opt-level = 3`, `lto = "fat"`, `codegen-units = 1`, and `strip = true`. The resulting binary is written to `target/release/azo-type` (or `target\release\azo-type.exe` on Windows).

## Command-Line Options

`azo-type` accepts optional CLI arguments at startup (parsed in `app/src/lib.rs`):

| Invocation | Behavior |
| :--- | :--- |
| `azo-type` | Starts directly in an in-memory blank Typst project ready for immediate editing. |
| `azo-type <folder>` | Opens the specified project directory if it exists on disk. |
| `azo-type --screenshot <path>` | Headless CI capture mode: renders the UI, writes a PNG/JPEG screenshot to `<path>`, and exits. |
| `azo-type --screenshot=<path>` | Equivalent equals-sign form for screenshot output. |
